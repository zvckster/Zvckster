### About

I work on the defensive side of security: getting logs into the SIEM, turning them into clean, structured events, and writing detections that hold up in production. I also enjoy the offensive side of the same problem, reading disclosures closely and rebuilding them to understand exactly why a system fails.

I care about tooling that removes repetitive work from analysts, and about documentation that someone else can actually follow.

### Focus areas

| Area | What I work on |
|---|---|
| Log onboarding | Parsing CEF, LEEF, key=value, JSON, CSV and syslog sources into normalized fields |
| Detection engineering | Wazuh decoders and rules, field normalization, testing detections against real samples |
| Vulnerability research | Reproducing published vulnerabilities, proof-of-concept tooling, mitigation guidance |
| Automation | Small, dependency-free tools in Python, Go, C and JavaScript |
