### About me

I design the technical foundations that make security operations effective, scalable and resilient. My work sits where architecture meets the day-to-day reality of a SOC: turning raw, messy telemetry into clean and trustworthy events, turning those events into detections that analysts can act on, and turning repetitive analyst work into automated, agent-driven workflows.

I think in systems. A detection is only as good as the log that feeds it, and a log is only as good as the pipeline, the decoder and the architecture behind it. That is why I work across the whole chain, from ingestion design down to the last regex.
