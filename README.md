### About

I design the technical foundations that make security operations effective, scalable and resilient: getting logs into the SIEM, turning them into clean, structured events, and building detections that hold up in production.

I care about tooling that removes repetitive work from analysts, and about documentation that someone else can actually follow. Outside of engineering work, I train people in cybersecurity, report phishing campaigns, and run my own self-hosted infrastructure.

### Focus areas

| Area | What I work on |
|---|---|
| SIEM architecture | Designing ingestion pipelines and SIEM deployments that scale |
| Log engineering | Parsing CEF, LEEF, key=value, JSON, CSV and syslog sources into normalized fields |
| Detection engineering | Wazuh decoders and rules, field normalization, testing detections against real samples |
| Threat hunting and analysis | Hunting across telemetry, malware analysis, vulnerability research |
| Automation | Python, APIs and CI/CD pipelines for security operations |
